如何获取 API Key

使用 Claude（Anthropic）

打开控制台访问：console.anthropic.com
注册或登录点击"Sign Up"注册，填写邮箱和密码。
添加付款方式进入"Billing"页面添加信用卡，每条消息费用极低。
创建 API Key点击"API Keys" → "Create Key"，起个名字后创建。
粘贴到设置里Key 格式为 sk-ant-… 开头。回到设置，选"Claude"，粘贴到 API Key 框。Key 只存在本地，不会上传。

使用 DeepSeek

打开开放平台platform.deepseek.com
注册或登录用手机号或邮箱注册，国内用户无需科学上网。
充值进入"充值"页面，最低充值 10 元，价格极低。
创建 API Key点击"API Keys" → "创建 API Key"，输入名称后生成。
粘贴到设置里Key 格式为 sk-… 开头。回到设置，选"DeepSeek"，粘贴到 API Key 框。
